# Amaru governance evidence bundle — v0.2

**Corpus record; not an accounting audit or an Observatory judgment.**

## Source and scope

This bundle derives observational records for three governance actions (2025 budget Info Action, 2025 and 2026 withdrawals) from `sources/cardano-governance/koios/2026-11-03/koios-proposal-list-raw.json`.

Pinned SHA-256: `8836d85e6530613d9042cc1f1d7e11e9e6e5a8e9391cda32be527f5a63e7fcd8`.

Retrieval: `2026-11-03T20:42:44.166123+00:00`; Koios `proposal_list`, a snapshot of indexed ledger information with proposer-authored `meta_json`, not separately fetched IPFS originals.

The bundle resides in a case directory because it records relations between actions; **the stable lookup key is the full governance action ID**, not the name Amaru or the HTEP case ID. The accompanying `action-index.csv` supplies an action-ID-to-directory lookup. Add its rows to a repository-level index if maintaining one. The directory remains an evidence grouping, not a project identity claim. This indexing choice should be reviewed before adding unrelated cases.

## Files and status

- `actions.csv` — source-derived action rows including `expired_epoch` and `dropped_epoch`. Blank withdrawal amount and count for InfoAction means *not applicable*, not zero.
- `withdrawals.csv` — ordered recipient stake addresses and lovelace amounts from Koios `withdrawal` lists; these do not establish payments made out from the recipients.
- `sources.csv` — original metadata URLs and locators in the pinned snapshot.
- `relationships.csv` — three reviewed, proposer-attested relations. **Not generated by the extractor.** An explicit transaction-hash matching transformation supports the A1→A0 link.
- `reported-returns.csv` — five proposer-reported refund amounts and transaction references in A2's motivation; **no independent transaction or amount verification**.
- `action-index.csv` — governance action ID lookup for the bundle (not intended to encode a universal proposal schema).
- `build_case.py` — deterministic extractor for all files above *except* `relationships.csv`.

## Minimal relation vocabulary v0.2

`continuation_of`: a later funding request explicitly identifies itself as continuing/following an earlier withdrawal; this is a curator classification based on the proposer's text, not a proven equivalence of scopes or project outcomes.

`references_prior_budget`: the later action explicitly links a preceding budget Info Action by governance action ID.

`follows_budget_statement`: a withdrawal proposal explicitly links an earlier budget statement by transaction hash; the lookup to the Info Action ID is a recorded transformation.

`assertion_type` reports what the proposer says. `relationship` is a **versioned classification** of that statement. `source_locator` grammar: `rows[proposal_id=<full ID>].meta_json.body.<field>` means find exactly one `proposal_id` in the pinned JSON's `rows` array, then navigate the named JSON fields. Text section suffixes after ` > ` designate a heading within the string, not a JSON key. `lookup_transformation` describes any additional matching step.

Info Actions have no on-chain enacted state under CIP-1694; A0's observed `expired_epoch=563` and `dropped_epoch=564` do not disprove a proposer's claim that an Info Action was *approved* in the sense of receiving a favorable vote. Vote tallies and relevant thresholds **are not in this `proposal_list` extraction** and have not been checked here.

## Reproduction

From the Corpus repository root (replace `CHECK_DIR` with a temporary output directory):

```bash
python records/htep-001/s1-amaru/build_case.py --snapshot sources/cardano-governance/koios/2026-11-03/koios-proposal-list-raw.json --out CHECK_DIR

git diff --no-index -- records/htep-001/s1-amaru/actions.csv CHECK_DIR/actions.csv
git diff --no-index -- records/htep-001/s1-amaru/sources.csv CHECK_DIR/sources.csv
git diff --no-index -- records/htep-001/s1-amaru/withdrawals.csv CHECK_DIR/withdrawals.csv
git diff --no-index -- records/htep-001/s1-amaru/reported-returns.csv CHECK_DIR/reported-returns.csv
git diff --no-index -- records/htep-001/s1-amaru/action-index.csv CHECK_DIR/action-index.csv
```

Use a distinct `CHECK_DIR` in the same working directory or adapt paths to your OS. `git diff --no-index` returns 1 on differences and 0 when files match. CSV output uses UTF-8 and LF consistently. `relationships.csv` requires manual source review.

## Evidence boundaries

- Koios snapshots are indexed source observations; downstream expenditure is not reconstructed.
- Proposed amounts, withdrawn lovelace, reported returns, and completed ledger transfers are distinct objects.
- The five refund transaction references are **not** ledger verified; no inferred net-spend field is provided.
- Labels are evidence interpretations with disclosed vocabulary, not ledger-native relations.
- No IPFS content hash validation, governance vote tally verification, audit, or technical outcome assessment was performed.

The record is usable independently of any Observatory case memo or HTEP hypothesis judgment.
