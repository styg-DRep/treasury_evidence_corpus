# Eternl governance evidence bundle — v0.1

**Independent Evidence Corpus record. Not a project audit, governance judgment, or cost benchmark.**

## Source and scope

Three Treasury Withdrawal actions from `sources/cardano-governance/koios/2026-11-03/koios-proposal-list-raw.json`, SHA-256 `8836d85e6530613d9042cc1f1d7e11e9e6e5a8e9391cda32be527f5a63e7fcd8`. Source retrieval: `2026-11-03T20:42:44.166123+00:00`. Original proposal metadata is represented by Koios-indexed `meta_json` and `meta_url`; separate IPFS re-fetch and hash verification have **not** been performed.

- **E1:** 2025 Intersect-administered maintenance withdrawal, ₳583,000; enacted.
- **E2:** 2026 Path to Sustainability request, ₳1,680,000; expired.
- **E3:** 2026 revised Path to Sustainability v2 request, ₳2,350,000; enacted.

`withdrawal` fields on an expired proposal describe the **requested** amount/recipient, not an executed treasury withdrawal. The two enacted requests total ₳2,933,000 in authorized withdrawals; this does **not** measure actual spending or payments to vendors. The three requests total ₳4,613,000 only as a nominal sum of requests; that sum is **not** funding disbursed.

## Files

- `actions.csv`: deterministic Koios fields, including both expired and dropped epochs.
- `withdrawals.csv`: original indexed recipient stake address, index, and requested lovelace amount; not downstream spend.
- `sources.csv`: snapshot row locator, metadata URL/hash and retrieval context.
- `action-index.csv`: three stable action IDs, to merge into the repository-wide `records/action-index.csv`. **Do not overwrite existing entries.**
- `build_case.py`: reproduces the four CSVs above from the pinned Koios snapshot.
- `relationships.csv`: **manually reviewed** source-backed links; definitions and locator syntax in `schemas/relations-v0.3.md`. Not generated by the script.
- `budget-claims.csv`: **manually reviewed proposer-attested figures**, with field/section locators. Not generated by the script. Denominations and estimation status are preserved.

The full action ID is the lookup identity; the case folder is a grouping of related evidence discovered during HTEP, not an asserted canonical identity for Eternl or its full history.

## Relationship and financial boundaries

E2 and E3 cite E1's 2025 treasury funding via an explorer link to its **transaction**; the documented transformation matches that hash to E1's `proposal_tx_hash` in the pinned snapshot. E3's preamble gives E2's full action ID directly. `revision_of` describes a distinct on-chain submission with revised terms; it does **not** imply that the earlier governance action was changed in place.

E3 attributes its modifications partly to CC feedback, but CC member vote rationales were **not** independently retrieved. E2's 2025 funding narrative includes financial-impact claims that do not verify actual operating costs. The 2026 requests use different approximate ADA/USD planning rates and audit allocations; neither demonstrates paid rates or actual audits.

The 2026 rationale also lists earlier Catalyst and other engagements. These are **out-of-scope documentary references**, not verified additional funded actions in this bundle. This deliberate boundary prevents an incomplete cross-mechanism graph from being mistaken for a complete Eternl financing history.

## Reproduce

From the Corpus repository root, choose a fresh `CHECK_DIR` (any empty output directory):

```bash
python records/htep-001/s2-eternl/build_case.py --snapshot sources/cardano-governance/koios/2026-11-03/koios-proposal-list-raw.json --out CHECK_DIR

git diff --no-index -- records/htep-001/s2-eternl/actions.csv CHECK_DIR/actions.csv
git diff --no-index -- records/htep-001/s2-eternl/sources.csv CHECK_DIR/sources.csv
git diff --no-index -- records/htep-001/s2-eternl/withdrawals.csv CHECK_DIR/withdrawals.csv
git diff --no-index -- records/htep-001/s2-eternl/action-index.csv CHECK_DIR/action-index.csv
```

`git diff --no-index` returns 0 for identical content and 1 for differences; use separate commands so that each is inspected. CSV encoding is UTF-8 with LF endings; preserve `*.csv text eol=lf` in `.gitattributes`. Relationship and budget-claim rows require **source inspection**, not only byte reproduction.

## What this record does not claim

It does not establish treasury balances received by the operational entity, expenditure, financial audit completion, actual delivery outcomes, CC members' reasoning, or reconciliation of prior Catalyst awards. Missing evidence is not a zero value. This record remains usable without the Observatory's S2 memo.
